**Leonida Platinum Guide** — an offline GTA VI trophy guide and tracker for PlayStation 5. All 55 trophies with their official names, descriptions and grades, a guide to each one written in our own words with its sources named, a four-phase roadmap to the platinum, every missable trophy flagged, and a checklist that saves your progress in the browser (with filters, a spoiler setting that hides hidden trophies, target counters, export and import). It runs entirely from its own files with the network off — no Rockstar logo or official artwork anywhere.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 (or build the hand-in with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`).
