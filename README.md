**Leonida Platinum Guide v2** — an offline GTA VI trophy guide and tracker for PlayStation 5. All 55 trophies with their official names, descriptions and grades, each with a cited answer first and a step-by-step guide (190 cited steps across 10 dated sources, checked 21 Nov 2026), a four-phase roadmap to the platinum, all 13 missable trophies flagged, a source matrix and a disagreements panel where the sources differ, difficulty and estimated time on every trophy, and a checklist that saves your progress in the browser (filters, a spoiler setting that hides hidden trophies, target counters, export and import, a Next Up planner). It runs entirely from its own files with the network off — no Rockstar logo or official artwork anywhere.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 (or build the hand-in with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`).
